# Blacksmith dashboard

React/TypeScript working skeleton. The dashboard reads live API/database status
and submits a simulation-only, side-effect-free preflight request.

Use the [root workflow](../../README.md) and project-container tooling. Do not
install or run dependencies using host Node 14. OpenAPI types are generated by
the root build command.

Loading, HTTP failures, and incompatible responses are visible; no scheduler
metrics or real-execution capabilities are implemented.
