# Blacksmith dashboard

React/TypeScript build lab. The interface uses self-hosted variable typography,
an original animated isometric forge illustration, a real API/database readiness
snapshot, and an interactive request/response workbench.

The illustration is explicitly a design concept, not live job activity. Its
motion can be paused and respects reduced-motion preferences. The workbench
submits only the existing simulation-only, side-effect-free preflight request;
changing its label clears stale validation. No scheduler features were added.

Use the [root workflow](../../README.md) and project-container tooling. Do not
install or run dependencies using host Node 14. OpenAPI types are generated by
the root build command.

Loading, HTTP failures, and incompatible responses are visible; no scheduler
metrics or real-execution capabilities are implemented.

The UI tests cover payload inspection, stale result clearing, keyboard navigation,
reduced motion, and layouts from 320px through desktop. Browser screenshots and
JUnit reports are generated by the [E2E workflow](../../tests/e2e/skeleton.spec.ts).
